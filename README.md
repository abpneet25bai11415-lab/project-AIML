 Snake Game (Python)

 Overview

This project is a Snake Game developed using Python and Pygame. It is a classic arcade-style game where the player controls a snake that grows in length as it eats food, while avoiding collisions with walls and itself.

---

Features

* Real-time snake movement using keyboard controls
* Food generation at random positions
* Score tracking system
* Increasing difficulty (speed increases as score grows)
* Game Over screen with restart option

---

 Technologies Used

* Python
* Pygame

---

 How to Run

1. Install Python (if not installed)
2. Install Pygame:

   ```
   pip install pygame
   ```
3. Run the Python file:

   ```
   python snake_game.py
   ```

---

 Controls

* Arrow Keys → Move snake
* Q → Quit game
* C → Restart after game over
